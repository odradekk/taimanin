# 成人向剧本写作指导（通用版）

面向“以人物关系为骨、以性场面为肉”的文字游戏与小说剧本。核心主张只有一句：**性场面必须写到底；但写到多深、多放浪，取决于两个人（或角色与加害者）的关系走到了哪一步，而不取决于动作本身的激烈程度。**

全文不含任何具体作品、角色或情节，落笔时按所属世界观替换具体设定即可。

---

## 0. 三条铁律与一条底线

1. **绝不留白**：任何“灯灭了”“后来她记不清了”“那一夜很长”式的跳切与遮掩都是失职。性交、口交、指奸、自慰、调教、高潮，每一段都必须落到具体的动作、部位与生理反馈上。
2. **直白具象**：直接使用准确的身体与体液词汇——乳房、乳首、乳晕、腰腹、腿根、股间、阴唇、蜜缝、内壁、媚肉、子宫口、阴蒂、精液、白浊、蜜液。禁用“花径”“云雨”“禁地”“桃源”等古典隐喻或遮羞词。
3. **心理反差是骨**：最锋利的色气不在肉体本身，而在**意志与身体的背叛**。越是骄傲、强硬、端庄的人，被快感击穿时的落差越要写足。推进顺序永远是：
   **咬牙硬撑 → 身体先一步背叛 → 羞耻与愤怒 → 快感压垮意志 → 短暂清醒 → 再次崩解**。

> **边界底线：身体可以写得淫靡，人格绝不能改。**
> 她可以被写得腰软、失神、连一句完整的话都说不出来，但她的行为逻辑、价值观、口癖以及骄傲的来源，必须始终是她自己。凡是“因为身体被开发了，性格就彻底变成另一个人”的写法，只允许出现在胁迫线的后期，且必须伴随沉重的精神代价。

## 1. 内容分级（行为深度轴：做到哪一步）

| 级别 | 阶段名称 | 核心内容 |
| :--- | :--- | :--- |
| **L1** | 触碰觉醒 | 擦碰、体温传递、呼吸交错、第一次清晰意识到对方的异性侵略感 |
| **L2** | 半裸与自慰 | 揉乳、舔舐乳首、隔衣摩擦高潮、被注视下自慰、手指探入 |
| **L3** | 手交与口交 | 主动侍奉、含弄吞咽、唾液拉丝、在引导或指令下学习动作节奏 |
| **L4** | 初次插入 | 破处、撕裂痛感与见血、适应吞吐节奏、初次内射 |
| **L5** | 激烈交合 | 骑乘、后入、口交接插入、占有式淫语、连续高潮、体液交融横流 |
| **L6** | 凌辱与调教 | 拘束、催情药物、淫具、鞭笞、公开羞辱、异种/触手、肉体改造、精神洗脑 |

**注意：内容分级只解决“行为做到哪一步”，不解决“表现放浪到什么程度”。** 后者属于另一条独立坐标（见第 7 节“淫乱度刻度”）。落笔时两条轴必须严密对齐，否则会出现“关系尚在试探期，床上却已毫无顾忌”的人设崩塌。

## 2. 四拍节奏（单场戏的内部推进）

一段完整的性场面必须走完“起、承、转、极/落”的生理与心理梯度，按四个节拍推进：

- **一、侵入（起）**：前戏、剥衣、拘束、药效初显、言语挑逗或羞辱。节奏要慢，重点写体温升高、冷汗、肌肉紧绷，以及双方眼神与呼吸的变化。
- **二、攀升（承 → 转）**：插入或实质刺激开始，节奏由缓入急。生理反应必须逐级递进，不可从初触直接跳到失神。重点写水声、腰肢动作、内壁被撑开的胀满感，以及逐渐碎成气音的台词。
- **三、崩解（极）**：高潮顶点。必须具体写出：腰肢弓起、脚趾蜷缩、内壁痉挛绞紧、瞳孔失焦、生理性泪水、喉间溢出的长音、指甲抓破床单或皮肉。**注意：单篇场景内允许多次高潮，但真正击穿心理防线的最高“极点”只允许出现一次**，写多必腻。
- **四、余韵（落）**：急促喘息、全身脱力、体液顺着腿根滑落，最后必须落在一句**将人物拉回原本性格的台词**上。

四拍解决的是“单场戏内部”的呼吸感；跨场面的尺度演进，则由第 7 节的关系刻度驱动。

## 3. 世界观要素必须进床

这是成人向剧本区别于普通黄文的核心标志：**角色的能力体系、随身装备、抑制器、药物与印记，必须在快感失控时同步参与叙事**，绝不能一脱衣服就退化成两个毫无背景的普通人。

- **能力暴走**：快感冲顶时，角色体内的力量不受控地外溢——电弧乱窜、灵光明灭、气流掀翻帐幔、残像分裂、皮肤纹路亮起。**力量的失控比肉体高潮更令人羞耻**，因为它赤裸裸地暴露了“她连看家本领都控制不住了”。
- **残响与残影**：越是强大的角色，越容易在失控瞬间留下力量的惯性痕迹（例如一道依然维持着端庄备战姿态的残像，或一段在精神链接里重复了三遍的呼唤）。残影的体面与本体的狼狈，能拉出极强的戏剧张力。
- **抑制器 / 药物 / 印记**：
  - **抑制器**：力量被封锁的角色，要写出“连一丝火苗都凝聚不起来”的无力与屈辱；
  - **药物**：不要把催情药写成凭空捏造欲望的魔法，而要写成“卸掉她的克制，把她交还给自己压抑已久的身体本能”；
  - **印记**：用淫纹或契约印记的发烫、变色、蔓延，将内部生理反应外化为双方可见的视觉读数。
- **装备残留**：武器、护具、战术绑带、制服局部应在场面中持续在场（如陷进床垫的枪套、尚未解开的金属护腕、磕碰到皮肤的勋章），切忌一开场就把全身物件清理得干干净净。

## 4. 衣物必须在场

角色一旦彻底赤裸，场面的视觉层次与涩感往往瞬间掉一半。**好的性场面里，衣服从头到尾都在场，只是状态在不断瓦解。**

- **衣物与肉体绑定描写**：写乳房，就写它正被什么布料托着、勒着、压变形，或是顶出什么轮廓；写双腿，就写指尖隔着哪一层料子、卡在哪一道袜口上。
- **层次关系清晰**：外衣、内衬、胸衣、底裤、长袜与靴子，剥离顺序必须符合穿戴逻辑。视线与动作尚未触及的里层不必提前“透视报菜名”，剥到哪一层、露到哪一层，再写哪一层。
- **状态连续演进**：解到一半的排扣、崩飞的暗扣、推高到腰际的裙摆、挂在手腕上的袖管、只褪下一只的丝袜、卡在膝弯或脚踝的内裤、被拨开又滑回肩头的领口。**四拍节奏的每一拍，都要顺手刷新一次衣物的当前状态。**
- **布料即战场**：紧身衣写“被曲线撑开、绷出布纹、被汗水与蜜液浸成半透明”；丝绸写“兜不住形状、一松手便顺着肌肤滑落到腰窝”；繁复层叠的礼服或和服写“越是挣扎松散，越是凌乱地敞开”。
- **保留局部配饰**：手套、过膝长袜、颈环、发饰、腿环或战术绑带，完全可以整场留在身上——半遮半露的束缚感远比全裸更具冲击力。
- **制服即体面外壳**：制服象征角色的社会身份与自持。一层层剥开、弄皱、濡湿制服的过程，本身就是击碎其外在防御的叙事过程。

## 5. 五感配比

避免通篇只有视觉与机械动作，单场戏的感官描写建议按以下权重分配：

| 感官 | 建议占比 | 描写重点 |
| :--- | :--- | :--- |
| **视觉** | 35% | 身体部位与充血状态、衣物凌乱度、光影明暗、体液光泽与拉丝 |
| **触觉** | 25% | 体温差、濡湿感、软腻与坚硬的对比、肌肉的紧绷与痉挛、掌心摩挲的粗砺感 |
| **嗅觉** | 20% | 最容易被忽略却最能定调的一感：发香、酒气、苦药、汗味、金属与枪油、潮湿木头与青草、血腥与铁锈 |
| **听觉** | 15% | 黏腻水声、粗重呼吸、床架摇晃、窗外雨声、远处更鼓或钟鸣、布料摩擦与撕裂 |
| **味觉** | 5% | 深吻、口交、舐过皮肤时的汗液与咸涩；点染一两句即可，但必须具体 |

- **嗅觉要成对出现**：将一种日常或高雅的气息（她惯用的冷香、茶香、清酒）与一种情欲或暴烈的气息（热汗、精腥、苦药、铁锈）并置。反差越具体，现场感越真实。
- **幻想投射（第一人称视角专用）**：在动作停顿或凝视的间隙，插入一两句“若是此刻令她……恐怕……”的短暂推演，将眼前的画面推向更深一步的越界想象。每场戏点缀一两处即可，过多会显得油腻。

## 6. 对白引擎

**肉中必有话。** 哪怕在最激烈的交合段落，也绝不能只剩下拟声词与动作说明。

- **被快感撞碎也要把话说完**：越有性格的角色，越会试图维持语言完整。写出她一句话被顶撞截成三段、说到一半变调改口、咬着牙硬撑着把某个称呼、某句判断或某句不甘心讲完的过程。
- **第一人称的“我”不能哑巴**：第一人称极易滑向沉默的旁观者。“我”必须在场发声——给出指令（“看着我”“别忍着”“自己掰开”）、逼问确认（“疼吗”“是谁弄湿的”“还要吗”），以及说出那句彻底戳破窗户纸的越界台词。
- **对白分工明确**：受方主要承载**心理防线与自尊拉扯**（讨价还价、嘴硬否认、逞强、认输求饶）；攻方主要掌控**节奏引导与心理施压**（“慢一点”“可以叫出来”“还不肯承认吗”）。
- **床笫拌嘴是极佳的节奏调节器**：关系越熟稔的两人，越会在床上斗嘴。一句带着刺的逞强话被一次重重的挺腰直接撞碎成闷哼，比单纯写十句呻吟更有效。
- **高潮后的本色锚点**：每次高潮平息后，必须安排一句符合角色日常性格的台词（或动作），瞬间将她从纯粹的雌性状态拉回那个鲜活的具体人物。
- **淫语自称按刻度解锁**：关系尚浅时，连一句“我是你的”都羞于启齿；而在胁迫线后期，则会被逼着吐出最卑贱的自称（详见第 7、9 节）。

## 7. 淫乱度刻度（关系深度轴：放浪到什么程度）

**尺度的本质不是“这一场做了多激烈的动作”，而是“这两个人走到了哪一步”。** 同一个失态反应，发生在浅关系里是崩人设，发生在深关系里是情难自禁；对恋人是全然交付，对加害者则是尊严剥落。

### 7.1 自愿关系线

| 关系深度 | 允许出现的生理与言语表现 | 核心心理落点 |
| :--- | :--- | :--- |
| **浅（试探期）** | 脸红耳赤、压抑的闷哼、咬唇忍耐、打湿贴身布料、话到嘴边咽回去 | 紧张、戒备、羞耻、“我们不该是这样” |
| **中（放开期）** | 漏出呻吟、基础淫语（“还要”“别停”）、肢体主动迎合、少量拟声词、偶见 `❤️` | 开始诚实面对欲望，但事后仍会羞恼嘴硬 |
| **深（交付期）** | 台词断碎、短暂翻白、失神、嘴角溢津、`❤️` 密集出现、归属类淫语、失禁边缘 | 卸下防备彻底交付；事后羞得抬不起头 |
| **极深（无所顾忌）** | 阿嘿颜、持续翻白眼、高潮失禁、大声喊出“去了”、用下流词汇形容自己的身体、主动索求被弄坏 | 亲密到极致后的毫无保留；**事后必须补一句本色台词收束** |

- **自愿线铁律：她清醒地记得全部。** 过程中越是放浪形骸，事后回过神来就越羞耻、越想掩饰——「不许记在心里」「刚才的不算」「你敢说出去我就——」。这份事后的羞耻感是床笫放纵的对价，缺了它，深情交付就会退化成廉价的发情。
- **对象决定失态的意义**：在恋人面前的失态本质是**特权许可**（“唯独在你面前，我允许自己变成这样”），而非被迫屈服。她可以在承受不住时说“慢一点”“饶了我”，但绝不会说出充满恐惧与绝望的“求你放过我”——后者属于胁迫线。

### 7.2 胁迫线（非自愿 / 半自愿）

| 调教阶段 | 允许出现的生理与言语表现 | 核心心理落点 |
| :--- | :--- | :--- |
| **前期（抗拒）** | 咬紧牙关、死命闷哼、被药物或技巧强行逼出的生理反应、死也不肯叫出声 | 意志激烈抵抗，所有声音都是往肚子里咽的 |
| **中期（撕裂）** | 压不住的淫叫、被勒令大声报数、在旁观者或镜头前失态、淫纹/印记亮起 | 强烈的屈辱愤怒与肉体的诚实背叛剧烈冲撞 |
| **后期（剥落）** | 表面与自愿线极深期同级的失态（翻白、失禁、流涎、机械宣告高潮），但眼神彻底空洞 | 自我认知剥落、记忆断片、平静地称呼加害者为“主人” |

- **胁迫线铁律：事后只剩空洞与断片。** 同样一句淫靡的求饶或宣告，自愿线里她记得清清楚楚并为此脸红耳热；胁迫线里，她在事后甚至不敢相信那是自己发出的声音——「我……刚才说了什么？」

### 7.3 同一现象、两种写法（核心对照表）

| 生理/言语现象 | 自愿线（深 / 极深） | 胁迫线（后期） |
| :--- | :--- | :--- |
| **翻白眼** | 只在冲顶那一瞬，随即闭眼埋进他肩窝喘息，嘴里嘟囔“不许看” | 眼白翻上去久久收不回来，强光与镜头怼在脸上，旁观者在冷静记数 |
| **高潮失禁** | 憋不住漏出一小股，她自己先浑身僵住，羞愤欲泣，被他抱紧安抚“没事” | 当众失控淌湿地面，记录者在本子上冷漠记下“第几日，完全失禁” |
| **淫语自称** | 「我是你的……」——脱口而出后自己先慌乱捂住嘴 | 「这具身体是主人的。」——语调平直温顺，像在背诵口令 |
| **事后反应** | 羞恼、抓过被子蒙头、捶打对方、色厉内荏地要求“忘掉” | 目光呆滞、记忆模糊、被问起原本姓名与职务时停顿很久 |

> **警示**：分不清这张表的两列，就会把两情相悦写成凌辱施暴，或把残酷的暴行洗白成廉价的甜宠。

## 8. 淫叫 DNA 与符号规范

符号化拟声、颜文字与极端失态描写均可使用，但必须严格遵循第 7 节的刻度解锁。**每个角色必须拥有专属的“淫叫 DNA”**，严禁所有角色共用同一套呻吟模板。

### 8.1 按声线与性格分档

| 角色声线/性格 | 常用字眼 | 符号频次 | 核心写法 |
| :--- | :--- | :--- | :--- |
| **少女 / 清亮尖细** | 咿、咕、呜、嗯、呀 | `❤️` 稍多 | `❤️` 是“嘴硬的裂缝”——嘴上越不甘心，尾音越容易漏出甜腻符号 |
| **熟女 / 低沉共鸣** | 唔、喔、噢、哈啊 | `❤️` 少而重 | 全场克制，只在她自己都未料到的最深处重重漏出一次 |
| **冷淡 / 寡言低语** | 气音、碎字、半句 | 几乎不用 | 崩解时只有急促气音与断句；一旦出现符号，即代表防线彻底失守 |
| **强硬 / 上位命令** | 短促闷哼、咬牙压音 | 不用 `❤️` | 她的失态不在于叫声变娇软，而在于原本威严的命令句被一下下撞碎 |

**铁律：加害者与施暴者的台词一律不加任何情绪符号。** 他们的句子越干净、越像公文或日常指令，压迫感越强。

### 8.2 符号使用规则

- **可用符号**：`❤️`（快感外溢）、`～`（尾音拖长）、`！？`（失控的惊愕）、`……`（呼吸断裂与失神）、`——`（话音被动作撞断）。
- **数量上限**：深/极深关系单篇 3–6 处；中等关系单篇 0–2 处；浅关系篇目禁用 `❤️`。
- **允许位置**：仅限对白中的淫叫串、被撞断的半句话、失神后的呢喃短句。**严禁在旁白叙述中使用符号。**
- **克制连打**：同一位置最多叠加两个符号（如 `……❤️` 或 `——！？`），禁止连打一串符号。
- **拒绝纯水**：禁止出现“啊啊啊啊啊”式的纯单字堆砌，呻吟必须夹杂具体字眼与语义。

### 8.3 淫叫推进三拍

单次高潮的发声应遵循**“短串（初起）→ 长串（攀升）→ 断裂（顶点）”**的呼吸变化：

- **短串（初起）**：「唔……喔、嗯——咿……！」
- **长串（攀升）**：「呜、呜哇——不行、那里太深——❤️」
- **断裂（顶点）**：「……去了。要去了、去了……」

**顶点宣告句必须贴合人设**：傲娇好强型是「输了……我又输给你了」；威严自持型可能死死咬住下唇只漏出一个单音，或是彻底失语。凡是吐露了羞耻的淫语自称，紧接着必须写她的本能找补（捂嘴、别过头、把脸埋进枕头、事后勒令对方忘掉）。

此外，**声音必须落在具体空间里**：床架的吱呀声、窗外的暴雨、空旷走廊的回音、远处的更鼓——叫声被环境接住，场面才不会悬浮。

### 8.4 失态的具象拆解（忌用标签代描写）

不要在正文里直接丢出“她翻白眼了”“她露出了阿嘿颜”这种干瘪的总结词，必须拆解为连续的生理细节：

- **翻白眼**：眼球不受控地向上翻起，眼白漫过瞳仁，湿透的睫毛剧烈颤抖，生理性泪水从眼尾斜滑入鬓角；紧接着要么脱力闭眼，要么瞳孔失焦地望着天花板。
- **流涎**：唇角先一步濡湿，一线透明唾液顺着下颌滑落至颈侧；她下意识想咽回去却使不上力，只能任由舌尖无力地抵着齿列。
- **失禁**：必须先写**“憋”**（大腿死死夹紧、腰腹瞬间僵硬、连呻吟都骤然卡住），再写防线溃决那一小股温热的失控，最后重点写**她意识到自己做了什么的那一秒**——那一秒的空白与羞愤，比任何直白的排泄描写都更具色气。
- **阿嘿颜**：仅限自愿线“极深”阶段或胁迫线“后期”使用。自愿线必须在失神中保留一丝**“羞”**（如无意识抬手遮脸、偏头躲避视线）；胁迫线则必须写出彻底的**“空”**（面部肌肉被快感扯出痴态，眼底却毫无神采）。

## 9. 称呼与身份刻度（胁迫线专用）

在胁迫与调教线中，角色精神防线的瓦解可以直接用**“她如何称呼对方”与“如何自称”**精准丈量，这条语言刻度比任何旁白都直观：

| 调教阶段 | 对加害者的称呼 | 自我称呼 | 语气与精神状态 |
| :--- | :--- | :--- | :--- |
| **一、初囚** | 「你们」「滚」「杂种」 | 「我」或自身本名/头衔 | 居高临下的斥责与怒骂 |
| **二、僵持** | 沉默不语，或冷硬的「你」 | 「我」 | 拒绝承认对方身份，不肯给任何称谓 |
| **三、防卫** | 改用客观职务（「审讯官」「主任」） | 「我」 | 试图用公事公办的冷漠划清界限 |
| **四、混乱** | 开始记混名字，或在恍惚中喊错人 | 「我这种人」「我这副身体」 | 认知出现裂痕，尊严松动 |
| **五、彻底剥落** | 「主人」「大人」 | 「奴」「这条命」「这具肉体」 | 语调平静、空洞、顺从，毫无波澜 |

**反向用法同样极具张力**：让一个角色在漫长的受辱线里，哪怕身体已被开发到频频失禁，嘴上却始终咬死第一阶段的「你们」不肯改口——那一声沙哑的「你们」，就是她仅存的不屈灵魂。

## 10. 器物在场、先声夺人与排版节奏

- **器物必须有回响**：床上的交合不是发生在真空里。木床要摇晃作响，地板要磨出动静，桌上的茶碗要震颤乃至翻倒，门板要被撞得闷响，窗外的雨声、更鼓或钟鸣要作为背景节拍持续存在。
- **先声夺人（转场技法）**：场景切入或转换时，**先给声音或气味，再给视觉画面**。先写门轴转动的轻响、靴跟叩击地面的两声、走廊尽头压抑的喘息，或是未见其人先扑面而来的酒气与血腥味。
- **长短句与段落排版**：描写用绵密长句铺陈感官，对白用急促短句推进交锋。**到了高潮崩解处，允许单句独立成段**（一段仅一句话，甚至一行只有一个破碎的拟声词）。切忌在最激烈的段落堆砌密不透风的千字大段，会把高潮的窒息感与爆发力彻底糊掉。

## 11. 负面清单（严禁采用的写法）

以下写法看似能制造廉价刺激，实则会迅速摧毁人物质感与文本可读性：

- **超长堆叠定语链**：严禁出现两三百字不断句的翻译腔长句，或将一堆形容词与名词生硬捏合成怪异的复合词。**单句原则上控制在 60 字以内，单段描写控制在 200 字以内。**
- **将“畜化贬低”当作叙事默认值**：严禁在旁白或恋人视角中将角色统称为“母畜”“肉壶”“排泄器官”。这类极端侮辱词只能出自胁迫线加害者之口；或是在极深度的失控中由角色自己羞耻地吐露一次（核心在于“我居然说出了这种话”的心理震动），绝不可由叙述者直接代劳。
- **反复贴“身份标签”加冕**：忌用“高冷校花”“绝美贵妇”“倾城尤物”等网文俗套标签反复强调角色地位。人物的尊贵感与分量来自其具体言行、职责与过往经历，反复贴标签只会让角色变得廉价。
- **NTR / 苦主羞辱 / “零代价”的爽感框架**：本指南不采用以羞辱第三方苦主为乐的恶俗框架。胁迫线本质是残酷的暴行，必须在叙事中留下真实的代价：伤痕、烙印、档案记录、流言、创伤后遗症与剧情后果。
- **暗中窥视的猥琐第一人称**：第一人称“我”是场面的直接参与者与主导者，不是躲在暗处搓手的偷窥狂。欲望的表达应当直白、滚烫、具侵略性，但绝不能猥琐油腻。
- **毫无信息量的拟声词刷屏**：严禁靠“啊啊啊啊啊”“嗯嗯嗯嗯”凑字数。每一串呻吟都必须有发音变化、有呼吸断句、有她正在极力掩饰或试图表达的潜台词。

## 12. 交付前十二项自查

定稿前逐条核对，任意一条不达标即需返工：

1. **查留白**：全文是否有任何一处用“灯灭了”“一夜无话”等留白跳过了实质场面？
2. **查衣物**：脱衣之后，衣物与配饰是否仍在场（层次、凌乱状态、局部残留是否随节拍更新）？
3. **查五感**：五感描写是否失衡？最关键的**嗅觉**（好闻与不好闻的气味对照）写了吗？
4. **查对白**：交合最激烈的那一段，她说话了吗？第一人称的“我”说话了吗？
5. **查梯度**：生理反应是否走完了“起（侵入）→ 承/转（攀升）→ 极（崩解）”的完整递进，还是从初触直接跳到了失神？
6. **查余韵**：高潮平息后，是否有那句把她拉回原本性格的“本色台词”？
7. **查极点**：单篇场景里真正击穿防线的最高“极点”用了几次？（超过一次立刻删减合并，保留最重的一次。）
8. **查人设**：她在床上的反应与妥协方式，是否依然符合她在这个关系深度下应有的意志状态与性格底色？
9. **查刻度对齐**：本篇的“放浪程度（第 7 节）”与“关系深度”是否严格匹配？（是否犯了在试探期就写出极深期无所顾忌表现的错误？）
10. **查失态性质**：本篇中失态（翻白、失禁、淫语等）的心理落点写对了吗？（自愿线是“因信任而彻底交付”，胁迫线是“被强行剥夺控制权后的空洞”。）
11. **查世界观**：角色的能力体系、装备、抑制器或印记是否参与了床戏？（还是衣服一脱就退化成了普通现代人？）
12. **查视角**：第一人称叙述是否保持了在场的张力，有没有不自觉滑向猥琐的偷窥视角？
