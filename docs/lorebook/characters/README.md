## 编纂与创作通用准则

1. **命名与语言纯度**：中文剧情对话与叙述一律遵循上述标准规范译名，严禁掺杂日文假名或生硬拼音；
2. **守序基线与开局时间锚定**：以 **2082 年 4 月** 为绝对开局节点。五车全体在籍队员初始状态皆为未受污染的纯洁坚守状态；
3. **残酷性调性原则**：色情与恶堕属于魔界侵蚀世界的残酷底层逻辑，涉及俘获沦陷描写时须严格契合角色在档案中确立的心理反差与抵抗尊严，杜绝轻量化扁平化处理；
4. **代码同步原则**：后续更新 `src/game/data/characters.ts` 与主线剧本时，一切数值、称谓、忍术名及交互对话均须向本名册档案严格对齐。
