# 术语表

本规范表确立本项目后续一切剧情编剧、文案企划与角色设定的唯一标准用语体系。宏观世界观背景详见 [world.md](world.md)。

- **正名原则**：每一个核心世界观概念在中文正文中仅允许绑定一个标准规范词。若因剧本扩充确需引入新术语，必须先行提案并收录至本表完成规范审定，方可正式写入剧本。
- **语言纯度**：中文剧情台词与场景叙述中，严禁突兀夹杂英文字母缩写或日文汉字/假名词汇；本表所列日文原文与外文术语，仅供设定考据与源语言对照使用。
